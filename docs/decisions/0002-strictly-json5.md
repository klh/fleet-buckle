# 0002 — JSON5 settings and generated engine configuration

Buckle's authored settings use JSON5 under `deploy/settings/`; named Zod schemas validate them.
Secrets are runtime file paths. Compose describes service wiring and keeps its native YAML format.

LiteLLM engine configuration is generated by `tools/src/buckle.gen-engine-config.ts` from catalog
and approved engine settings. Test setup generates its fixture configuration. Azure Compose mounts
`deploy/engine/mscopilot.litellm.yaml`, a generated deployment artifact. Regenerate at the owning
source; do not hand-edit model rows. B02 in [the plan](../../tasks/plan.md) qualifies the production
source, version and loaded configuration. The historical claim that all engine YAML is generated
only inside the running container does not describe the checked-in Azure wiring.
